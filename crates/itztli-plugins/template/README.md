# {{name}}

An Itztli plugin.

- `plugin.json` says what it is, and its settings.
- `main.js` is its code: one ES module, no build step needed.
- `itztli.d.ts` describes everything `ctx` offers; with it, your editor
  completes and checks `main.js`.

Enable it for development in Settings → Plugins and it reloads every time you
save a file here.
