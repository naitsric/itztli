# Keyboard

Itztli uses the IntelliJ macOS keymap. Every action can be rebound in
Settings → Keymap (**⌘,**). On a link ⌘B follows it; elsewhere it is bold.

## Moving around

| Action                | Keys        |
| --------------------- | ----------- |
| Search Everywhere     | ⇧⇧          |
| Find Action           | ⇧⌘A         |
| Go to Note            | ⌘O          |
| Go to Heading         | ⌥⌘O         |
| Recent Files          | ⌘E          |
| File Structure        | ⌘F12        |
| Back / Forward        | ⌘[ / ⌘]     |
| Go to Declaration     | ⌘B          |
| Find Usages           | ⌥F7         |
| Find in Files         | ⇧⌘F         |

## Editing

| Action                         | Keys        |
| ------------------------------ | ----------- |
| Show Context Actions           | ⌥⏎          |
| Rename                         | ⇧F6         |
| Extract to Note                | ⌥⌘M         |
| Duplicate line or selection    | ⌘D          |
| Delete line                    | ⌘⌫          |
| Move line                      | ⌥⇧↑ / ⌥⇧↓   |
| Extend / shrink selection      | ⌥↑ / ⌥↓     |
| Add next occurrence            | ⌃G          |
| Bold / italic                  | ⌘B / ⌘I     |
| Reformat tables                | ⌥⌘L         |
| Insert Template                | ⌘J          |

## Tool windows

⌘1 Vault · ⌘2 Bookmarks · ⌘3 Find · ⌘4 Backlinks · ⌘5 Tags · ⌘6 Problems ·
⌘7 Structure · ⌘8 Graph. Press one again to hide it; **⇧⌘F12** hides them all.
