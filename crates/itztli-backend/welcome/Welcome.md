# Welcome to Itztli

*Itztli* is obsidian in Nahuatl. This is a vault: a folder of plain Markdown
files that stay yours, open in any editor, and go wherever you copy them.

> [!tip] The one key to remember
> Press **⇧⇧** (Shift twice) to search everything: notes, headings, text and
> every action.

## Look around

- [[Linking]]: how notes connect, and how renaming never breaks a link
- [[Keyboard]]: if your hands know IntelliJ, they already know this
- [[Formatting]]: everything Markdown can do here
- [[Plugins]]: make it do something it doesn't
